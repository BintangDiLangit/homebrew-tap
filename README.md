# BintangDiLangit Homebrew Tap

Homebrew casks for my tools. Works on macOS and Linux.

## Bastion

Local-first security review for developers and AI coding agents —
[BintangDiLangit/bastion](https://github.com/BintangDiLangit/bastion).

```sh
brew install --cask BintangDiLangit/tap/bastion
```

Installs three binaries: `bastion` (CLI scanner), `bastion-mcp` (MCP stdio
server) and `bastion-api` (HTTP API server).

```sh
bastion scan /path/to/project
```

## Notes

Casks in this tap are generated by
[GoReleaser](https://goreleaser.com) on each upstream release. Do not edit
`Casks/*.rb` by hand — the next release overwrites it.
